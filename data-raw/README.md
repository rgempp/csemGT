# data-raw/ — reference data for Sprint 2 parity tests

This folder contains two scripts that, together, generate the two files used
by the Sprint 2 `.ado`-parity tests:

| File | Lives in | Produced by |
|---|---|---|
| `gtcsem_reference_data.rds`     | `inst/extdata/` | `make_reference_data.R` (R) |
| `gtcsem_reference_results.dta` | `inst/extdata/` | `make_reference_results.do` (Stata) |

A third file, `data-raw/gtcsem_reference_data.dta`, is an intermediate that
moves the data from R into Stata. It is regenerated by the R script and lives
in `data-raw/` only (it is not distributed with the package).

## Run order

1. **R first.** From the package root:
   ```r
   source("data-raw/make_reference_data.R")
   ```
   This writes `inst/extdata/gtcsem_reference_data.rds` and
   `data-raw/gtcsem_reference_data.dta`. Requires the `haven` package.

2. **Stata next.** From the package root, with `gtcsem.ado` on the adopath:
   ```
   stata -b do data-raw/make_reference_results.do
   ```
   (or interactively: `do data-raw/make_reference_results.do`). This loads
   `data-raw/gtcsem_reference_data.dta`, runs `gtcsem` with
   `method(all) semethod(analytical) smooth excludeextremes cutpoint(median)`,
   harvests every `r()` scalar of interest into a constant column with the
   same name, and saves the augmented dataset to
   `inst/extdata/gtcsem_reference_results.dta`.

3. **Verify in R.** Re-launch R from the package root and quickly check:
   ```r
   ref <- haven::read_dta("inst/extdata/gtcsem_reference_results.dta")
   cat("N rows:", nrow(ref),
       "\nsigma2_p[1] =", ref$sigma2_p[1],
       "\nerho2[1]    =", ref$erho2[1],
       "\nphi[1]      =", ref$phi[1], "\n")
   ```
   Expected: 300 rows, all four scalars finite and positive (with
   `sigma2_p` of the order of 0.02–0.05 for the default Rasch-like
   simulation).

## Seed

The R generator uses `set.seed(20260513L)` (the date Sprint 2 opened, 2026-05-13).
Re-running step 1 reproduces the same `.rds` and `.dta` byte-for-byte across
platforms (R ≥ 3.6.0 default Mersenne-Twister + Inversion sampler). The Stata
ANOVA is deterministic, so step 2 also reproduces exactly across Stata 16+.

## When to regenerate

- Bumping the seed or the simulation design parameters in
  `make_reference_data.R` invalidates the reference. Regenerate **both** files,
  in order.
- A bump of `gtcsem.ado`'s numerical implementation that changes any of the
  reference quantities (it should not, but if it does) requires regenerating
  the `.dta` and updating the parity tolerances in
  `tests/testthat/test-csem_gt_parity_ado.R` only if the change is documented
  as intentional.
