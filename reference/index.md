# Package index

## Estimation

Per-person conditional standard error of measurement under the
single-facet person-by-item crossed Generalizability Theory design.

- [`csem_gt()`](https://gempp.cl/csemGT/reference/csem_gt.md) :
  Conditional standard errors of measurement under Generalizability
  Theory

## S3 class and methods

The `csem` object and the methods that operate on it.

- [`new_csem()`](https://gempp.cl/csemGT/reference/new_csem.md) :
  Construct a \`csem\` object
- [`is.csem()`](https://gempp.cl/csemGT/reference/is.csem.md) : Test
  whether an object is a \`csem\` object
- [`print(`*`<csem>`*`)`](https://gempp.cl/csemGT/reference/print.csem.md)
  : Print a \`csem\` object
- [`summary(`*`<csem>`*`)`](https://gempp.cl/csemGT/reference/summary.csem.md)
  : Summarise a \`csem\` object
- [`plot(`*`<csem>`*`)`](https://gempp.cl/csemGT/reference/plot.csem.md)
  : Plot a \`csem\` object
- [`as.data.frame(`*`<csem>`*`)`](https://gempp.cl/csemGT/reference/as.data.frame.csem.md)
  : Coerce a \`csem\` object to a data frame
- [`by_score()`](https://gempp.cl/csemGT/reference/by_score.md) :
  Extract the score-level table from a \`csem\` object
- [`coef(`*`<csem>`*`)`](https://gempp.cl/csemGT/reference/coef.csem.md)
  : Extract the variance components of a \`csem\` object

## Datasets

Simulated illustration datasets shipped with the package.

- [`iowa_like`](https://gempp.cl/csemGT/reference/iowa_like.md) :
  Simulated ITED-like dichotomous responses (Brennan, 1998)
- [`ipip_like`](https://gempp.cl/csemGT/reference/ipip_like.md) :
  Simulated IPIP-10-like Likert responses
